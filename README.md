# Plataforma ZELURBIS

A **ZELURBIS** é uma plataforma tecnológica dedicada ao desenvolvimento de soluções para gestão urbana sustentável.

Sua primeira solução é o **EcoAçaí**, um sistema voltado ao gerenciamento da coleta de caroços de açaí, promovendo organização operacional, rastreabilidade e apoio à economia circular.

---
